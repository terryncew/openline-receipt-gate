# RGV-P34

`RGV-P34` is the exploratory 34-candidate signal check created after the independent GDPa3 truth needed by RGV-001 was unavailable.

It does not replace RGV-001.

The pilot inherits the exact 34-candidate cohort constructor from `TRIAL-SELECTOR-EXTERNAL-001`, then evaluates three frozen developability dimensions using fully nested leave-one-antibody-out prediction.

A positive verdict is `PILOT_VETO_SIGNAL`, explicitly graded `EXPLORATORY_INTERNAL_PILOT`.

A negative verdict is `NO_PILOT_VETO_SIGNAL` and closes the learned selector/veto line under the frozen stop rule.

No result from P34 may be described as external validation.
