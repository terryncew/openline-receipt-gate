# RGV-001 — Reality Gate

RGV-001 is a deliberately adversarial follow-up to the closed CPG selector line.

It does **not** ask whether a model can rank the best antibodies. It asks whether a conservative sequence-only model can identify a high-confidence failure tail before scarce wet-lab capacity is spent.

The primary truth is a joint viability region over HIC, PR-CHO, and AC-SINS pH 7.4. The gate emits only `VETO` or `UNKNOWN`; there is no `PASS`.

Model selection and uncertainty calibration use GDPa1's frozen cluster-aware folds only. GDPa3 is touched once for the external verdict.

The learned gate must preserve >=95% of experimentally clean GDPa3 antibodies, avoid >=50% of experiments, and beat the best nonrandom baseline by >=10 percentage points in experiment avoidance while that baseline is also held to the 95% clean-retention floor. A preregistered ±5% threshold stress probe must preserve the direction.

If it fails, the learned viability-veto hypothesis closes. This benchmark must not be used to claim prediction of clinical success.

The Nature/AIntibody motivation is conceptual rather than a shared dataset: weak ability to identify the *best* candidate does not logically imply weak ability to reject candidates that clearly violate non-compensable constraints.
