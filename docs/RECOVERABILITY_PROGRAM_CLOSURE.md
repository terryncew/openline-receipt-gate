# Recoverability program closure

**Disposition:** `NO_DOMAIN_INDEPENDENT_RECOVERABILITY_MARGIN_SIGNAL`

The useful intuition survives: options can disappear before catastrophe, and delay can eliminate the last useful intervention.

The stronger claim is closed. The current record does not support a universal curve, margin, or state-only scalar that reveals remaining recoverability across unrelated domains.

The missing object is the transition under intervention:

```text
(state/history, action, lag) -> outcome distribution
```

An action name alone is insufficient. Observations of danger describe one realized path; they do not establish what another intervention, or the same intervention at another delay, would have done.

A domain model may compute and display contraction of a feasible action set. That display is downstream of the intervention model. It is not an independent universal predictor.

## Reopen rule

The line remains closed until a candidate first passes `INTERVENTION-SUFFICIENCY-001`:

1. matched context under multiple actions;
2. matched context-action pairs under multiple lags;
3. successful and failed outcomes;
4. remedy divergence under the same matched context, target, constraints, and lag;
5. lag contraction: the same context-action succeeds earlier and fails later.

The first comparator after PASS must be a strong direct action-conditioned transition model. A future Terrynce-style summary earns a role only by improving transfer, calibration, robustness, compression, interpretability, or safety without discarding needed intervention information.

## OpenLine boundary

```text
admissible evidence + history
        |
        v
domain transition model
        |
        v
feasible action set under target/constraints/lag
        |
        v
Mandate / Policy Gate
        |
        v
authorized action set -> execution -> receipt
```

Receipt Gate verifies evidence and model standing. Frame Ledger carries history. The domain model estimates intervention outcomes. Mandate/Policy Gate applies authority. Results expire. A changed feasible or authorized set can reopen prior decisions.
