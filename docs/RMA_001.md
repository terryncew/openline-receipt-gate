# RMA-001

**Question:** when prediction cannot safely replace physical evidence, can it allocate physical evidence more efficiently?

This benchmark simulates sequential revealing of the same three frozen developability assays used by RGV-PILOT. It never allows a model prediction to become a VETO or RETAIN decision.

## Result

`NO_MEASUREMENT_ROUTING_SIGNAL`

The strongest fixed assay order required 518 reveals. Sequence-adaptive routing required 514: a 0.8% improvement whose 95% bootstrap interval crossed zero. It did not clear the frozen promotion bar, so the three-assay routing hypothesis is closed on this substrate.
