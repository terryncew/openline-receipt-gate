# RMA-001

**Question:** when prediction cannot safely replace physical evidence, can it allocate physical evidence more efficiently?

This benchmark simulates sequential revealing of the same three frozen developability assays used by RGV-PILOT. It never allows a model prediction to become a VETO or RETAIN decision.

The canonical post-run output is `rma-001-report.md`, which puts the cohort, authority boundary, measurement counts, savings, confidence intervals, verdict, prior result, claim boundary, and stop rule on one page.
